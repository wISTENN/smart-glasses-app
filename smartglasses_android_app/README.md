# SmartGlasses Android App

Минимальное Android-приложение для подключения самодельных очков к телефону по Bluetooth.

## Что умеет
- ищет сопряжённые Bluetooth-устройства
- показывает список найденных очков
- подключается к выбранному устройству
- отправляет тестовую команду
- отображает базовый статус: батарея, температура, сигнал

## Как открыть в Android Studio
1. Откройте папку `smartglasses_android_app` в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Подключите Android-устройство или запустите эмулятор.
4. Нажмите Run.

## Что нужно подстроить под ваши очки
В файле:
- `app/src/main/java/com/smartglasses/app/MainActivity.kt`

Нужно поменять:
- UUID сервиса/характеристик Bluetooth
- формат команд
- обработку входящих данных

Пример:
```kotlin
val uuid = UUID.fromString("00001101-0000-1000-8000-00805F9B34FB")
```

Если у ваших очков свой протокол, замените UUID и `PING\n` на реальные команды.

## Типовой сценарий для самодельных очков
Схема обычно такая:
- очки = Bluetooth-модуль (HC-05, BLE, ESP32, nRF52 и т.д.)
- телефон = Android-приложение
- обмен = строки, JSON или бинарные пакеты

## Важно
Если очки передают данные не через RFCOMM, а через BLE GATT, потребуется отдельная реализация:
- `BluetoothGatt`
- `BluetoothGattCallback`
- чтение Characteristic
- отправка Write/Notify
